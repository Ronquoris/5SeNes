    How this works

    • Detects people, vehicles, cyclists and animals using an on-device model, and names the object when it is approaching or very close.
    • Also watches a ground strip and a head-height strip of the frame for sudden, sustained changes, and gives a generic "watch your step" or "obstacle ahead, duck" warning once the change holds for a moment — this is a simple visual heuristic, not a trained pothole/branch detector, so it can't name what it is.
    • Looks for repeated horizontal banding low in the frame (a rough stand-in for a staircase) and warns "stairs ahead".
    • On a phone, uses the tilt sensor to notice when the path starts sloping and says "path going uphill" or "path going downhill" — works best when the phone is held steady and facing forward.
    • Every alert is also shown as text here, so it works with screen readers.
